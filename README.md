# Tauri Data Beautifier

[![Rust Unit Tests](https://github.com/Doble-Technologies/JSON-Beautifier/actions/workflows/release.yml/badge.svg)](https://github.com/Doble-Technologies/JSON-Beautifier/actions/workflows/release.yml)

A beautiful, snappy, and lightweight desktop app for formatting JSON, XML, YAML, and other data formats in Rust using the Tauri framework.

## Features

* Format JSON, XML, YAML, and other data formats with ease
* Customizable formatting options for each format
* Lightweight and snappy, fast and efficient
* Cross-platform support (Windows, MacOS, and Linux)

## Getting Started

To get started with Tauri Data Beautifier, follow these steps:

1. Install Rust using the official instructions from [here](https://www.rust-lang.org/tools/install).
2. Clone this repository or download the source code.
3. Run `cargo build` to compile the project.
4. Run `cargo run` to start the app.

## Usage

To use Tauri Data Beautifier, simply open the app and drag and drop a data file into the app window. The app will automatically format the data according to the selected formatting options.
